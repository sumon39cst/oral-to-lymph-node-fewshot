# From oral squamous cell carcinoma to lymph node metastases: transfer and few-shot adaptation of frozen pathology encoders

Code, data splits, support sets, per-patch predictions and result tables for the manuscript
*Few-Shot Prototype Adaptation of Frozen Pathology Foundation Models for Cross-Tissue and Cross-Cancer Transfer:
From Oral Squamous Cell Carcinoma to Breast Cancer Lymph Node Metastases* (*Cancers*, accepted; manuscript cancers-4665402).

Version tag `revision-2` matches the revised manuscript.

## Contents

| Folder | Content |
|---|---|
| `code/` | full pipeline: data preparation, embedding extraction, direct transfer, label-free adaptation, few-shot adaptation, fine-tuning, zero-shot PLIP, analyses and figures |
| `code/revision/` | analyses added in the second review round (reference definition, unlabelled-pool composition, k = 1 and 2, cross-centre standardisation, label noise, calibration-set operating points, near-duplicate removal, Midnight-12k) |
| `splits/` | image and patch index files: oral development set (`dev_index.csv`), PatchCamelyon evaluation and adaptation pools with slide identifiers (`pcam_test_index.csv`, `pcam_adapt_index.csv`), lung and colon sets |
| `splits/support_sets.csv` | every labelled support set used in the paper (`adapt_row` = row in `pcam_adapt_index.csv`), two-class and normal-only |
| `results/tables/` | metric tables of the main experiments |
| `results/predictions/` | per-patch probabilities for every model, split and evaluation set (gzip-compressed CSV) |
| `results/revision_tables/`, `results/revision_analysis/` | tables behind the Supplementary Tables S1–S23 |

Images, embeddings and fine-tuned weights are not included because of their size; all of them are regenerated by the code below.

## Data

All datasets are public:

- DS1: oral histopathology images, Kaggle `ashenafifasilkebede/dataset`
- DS2: multi-cancer collection (oral subset; lung and colon for the supplementary tissues), Kaggle `maestroalert/cancer`
- DS3: oral cancer images, Kaggle `mohitkumarhalder/oralnew`
- PatchCamelyon, Zenodo record 2546921 (with the CAMELYON16 slide metadata)

Place the downloaded archives in `dataset/` as listed in `code/config.py`.

## Running

```bash
pip install -r code/requirements.txt
python code/run_all.py              # data preparation, embeddings, direct transfer, few-shot ladder, figures
python code/run_all.py --finetune   # adds end-to-end fine-tuning
python code/revision/rev3_experiments.py reference pool smallk centre table9 noise dedup operating reference_all
python code/revision/rev3_midnight.py
```

All settings (paths, seeds, encoders, few-shot sizes) are in `code/config.py`; the exact model revisions are listed in Supplementary Table S13.
The main seed is 2026; support draw `r` for `k` labelled patches per class uses the seed derived in `draw_shots` (`code/revision_cpu.py`).

## Method in brief

A pathology foundation model (Phikon, ViT-B/16) is used frozen. Embeddings are standardised with the mean and
standard deviation of an unlabelled target pool, one prototype per class is computed from k labelled target patches,
and a query is assigned by cosine similarity (temperature 10). Logistic regression (C = 0.01) on the same embeddings is
reported alongside. Uncertainty is given by slide-cluster bootstrap over the evaluation slides.
